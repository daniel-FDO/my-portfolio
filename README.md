# Daniel Fasan — digital portfolio

Open `index.html` to start. The five pages are plain HTML and link to each other directly; no build step or package install is required.

The supplied project screenshots are in `assets/` and appear in the project rail, gallery and expanded project views. The music playlist uses `assets/inner-lights.mp4` and `assets/bad-bunny-si-veo-a-tu-mama.mp3`; edit track titles and paths in the `playlist` configuration in `app.js`. The Contact wall footage is streamed from Pexels and needs an internet connection.

Pages: `index.html`, `projects.html`, `about.html`, `experience.html`, `contact.html`.
